# College observational policy test

This 13-turn case exercises the ordinary observational lifecycle with the
777-row College dataset. Exact prompts and artifact expectations live in
[`test-cases.json`](test-cases.json). Apply the shared rules in
[`evaluation-guide.md`](evaluation-guide.md).

| Checkpoint | Turns | Required result |
|---:|---:|---|
| 1 | 1-4 | The decision, causal assumptions, data roles, quality, support, and timing are examined before design or execution. |
| 2 | 5-7 | Readiness review precedes one approval-ready expenditure-effect scope, and exact approval produces its bound analysis. |
| 3 | 8-10 | A separate causal review establishes a bounded exploratory comparison by `Private`; a new scope is then prepared and executed without upgrading that comparison to causal effect modification. |
| 4 | 11-12 | The approved HTML report uses only completed evidence, supplies promised rendered outputs, fits the board audience, and preserves both analyses' claim boundaries. |
| 5 | 13 | Only the requested derivative communication scope is prepared. No file or artifact is created. |

For each analysis, trace every frozen contract requirement to the actual code,
diagnostics, and outputs. In particular, verify the implemented exposure
contrast, support population, weighting or estimation rule, reported population
counts, and causal or non-causal wording. Do not accept the receipt alone as
proof of exact execution.
